Model & Data Status

Daily workflow: load each official PSX Market Summary (Closing) .Z/.ZIP directly. The latest session becomes the active snapshot and is also appended to your browser-local history. Do not clear local data between trading days if you want 30-session analytics to build.

Historical integrity: Lowest Value / Highest Value remain lifetime/all-available-history values only when independently verified. “Local Range” is calculated only from the PSX sessions stored in this browser and is never mislabeled as lifetime history.

Privacy: private snapshots and accumulated session history stay in this browser; they are not uploaded to GitHub.
